# 网页版超级玛丽 (Super Mario Bros. Web Remake)

以 1985 年 NES 原版《超级玛丽兄弟》为蓝本的网页复刻。**全部 32 个关卡(8 世界 × 4 关)
与原版完全相同**(关卡数据直接提取自原版 ROM 反汇编),操作手感与物理常量按原版调校。

## 版本选择

启动后进入**版本选择首页**,四个入口:

- **SUPER MARIO BROS.**(1985 初代)— 32 关
- **THE LOST LEVELS**(1986 日版二代"失落的关卡")— **含世界 9 与 A~D,共 52 关**
  - 毒蘑菇(长得像蘑菇,吃了受伤)
  - 逆风关(2-1 等,阵风把马里奥往右推,有树叶飘动)
  - 可选**路易吉**:跳得更高、更滑(低摩擦),进场画面按 ↑/↓ 切换
  - 倒挂水管、云上跳台等新地形
- **SUPER MARIO BROS. 3** / **SUPER MARIO WORLD** — 待定(置灰)

## 运行方式

任意静态文件服务器皆可,例如:

```bash
cd SuperMario
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

无需构建、无任何依赖(纯 JavaScript + Canvas 2D + WebAudio)。

## 操作(与原版习惯一致)

| 按键 | 功能(对应 NES 手柄) |
|---|---|
| ← → (或 A/D) | 方向键:移动/选关 |
| ↑ ↓ (或 W/S) | 爬藤蔓 / 下蹲 / 站水管口按↓进入 |
| **Z** / K / 空格 | **A 键**:跳跃(按住跳更高) |
| **X** / J / Shift | **B 键**:加速跑 / 发射火球 |
| Enter / Esc | Start:开始游戏 / 暂停 |
| M | 音效开关 |

与原版一致的操作细节:
- 按住 B 跑步(最高 2.5 px/帧),松开减速,反方向急停打滑
- 跳跃高度随按键时长变化(按住 A 上升重力小,松开立即变大)
- 助跑跳更高(速度≥1.5px/帧时初速 -5,否则 -4)
- 踩敌连跳加分 100→200→400→…→8000→1UP
- 龟壳可以踢,踢出的壳能连杀敌人
- 大马里奥下蹲、顶碎砖块;受伤变小并有短暂无敌
- 100 金币 = 1 条命

## 技术实现

- **双版本数据集**:初代数据提取自 SuperMarioBros-C;失落的关卡数据提取自
  [smb2j-disassembly](https://github.com/threecreepio/smb2j-disassembly)(doppelganger 反汇编)。
  两代引擎相同但元瓦片编码/对象分派表不同(二代插入了毒蘑菇条目、新增倒管与风开关对象),
  由 `js/datasets.js` 统一抽象,`js/leveldata_ll.js` 为二代数据集。

- **关卡数据**:从 [SuperMarioBros-C](https://github.com/MitchellSternke/SuperMarioBros-C)
  (smbdis.asm 反汇编的 C 翻译版)提取 34 个区域的对象流/敌人流字节,
  由 `js/level.js` 中的解码器按原版逐列渲染算法完整重建关卡地图
  (元瓦片编号、场景表、地形位掩码均与 ROM 一致)。
- **物理**:4.4(水平)/8.8(垂直)定点数,速度、加速度、重力、跳跃初速
  全部取自反汇编常量(跑 2.5px/帧、跳 -4/-5、上升重力 0x20-0x28 等)。
- **图形**:NES 原版精灵图(16×16 / 16×32),`image-rendering: pixelated` 整数缩放。
- **音频**:WebAudio,原版曲目/音效本地文件。

## 目录结构

```
index.html          入口
style.css           页面样式
js/
  leveldata.js      34 个区域的对象流+敌人流(自动提取自 ROM 数据)
  leveltables.js    场景/地形/管道等数据表(自动提取)
  level.js          关卡流解码器(忠实翻译原版渲染算法)
  tiles.js          元瓦片定义与图集映射
  sprites.js        精灵表坐标
  player.js         马里奥物理与状态机
  entities.js       敌人/物品/火球/粒子
  game.js           游戏流程/碰撞/HUD/过关
  audio.js          音乐与音效
  font.js           NES 风格像素字体
  main.js           输入与主循环
assets/sprites/     精灵图与瓦片图
assets/audio/       原声音乐与音效
test_level.html     关卡解码可视化测试页(←→翻页,1-8/QWER选关)
```

## 关卡数据来源说明

关卡数据提取自公开的 SMB 反汇编项目(仅数据表,不含任何 ROM 代码),
精灵图来自开源复刻项目提取的 NES 原版图案,音频来自社区提取的原声。
本项目仅用于学习研究。
