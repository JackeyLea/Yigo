# Yigo

通用游戏框架

## 提示词

我想开发一个通用游戏框架，这个框架可以玩麻将、斗地主、五子棋、围棋、象棋、黑白棋、德州扑克等常见的棋牌类游戏。附件是已有的框架需求和德州扑克需求。帮我扩展完善需求。同时给出框架设计需求，常见的五子棋、黑白棋、德州扑克等游戏的设计需求。

修复p0中19项阻塞性问题。然后进行phase1中数据库设计、基础架构搭建、ci/cd。继续phase2 大厅系统、用户体系、房间管理、插件框架。然后是phase3网络通信、状态同步、匹配系统、AI引擎，修复接口一致性。继续Phase 4，7款游戏插件逐款实现，插件接口最终确定。继续Phase 5，社交、成就、排行、回放。最后是10项内容遗漏
，新手引导、邮件通知、充值流程、赛季机制、防沉迷系统、德州Tournament详细规格、分享功能、运营后台、道具系统、实时语音。整体策略是完善需求和设计然后根据设计进行开发

先修复p0问题，插件沙箱使用vm模块，钱包freeze/unfreeze api确实，eventbus订阅接口不完整。然后完成框架核心+7款游戏+基础社交、经济。

然后完成p1遗漏功能，经济、社交、运营中遗漏的破产补助、抽奖/转盘、VIP体系、礼包系统
、俱乐部/公会、实时语音（部分）、逃跑惩罚
、用户行为分析、留存率统计、推送通知。然后进行测试
